# Fractal Flames

Gerador de fractal flames (IFS) em um único arquivo HTML, sem dependências. Abra `index.html` no navegador.

- **Espaço** ou clique: nova flame
- **P**: troca a paleta
- **S**: salva PNG
- A semente fica na URL (`#semente.paleta`), então dá para guardar o link de uma flame que você gostou.
